Silverfin is a cloud connected-accounting platform for accountancy firms and finance teams that standardises and automates the financial close. It pulls ledger data from bookkeeping systems, runs working papers, reconciliations and analytical review through a Liquid-based templating language, and produces reports, PDF exports and compliance filings. Founded in Ghent, Belgium and now part of Visma, Silverfin exposes a v4 REST API plus a dedicated SyncAPI that let third-party bookkeeping software and integrators submit transactions, manage companies, periods and accounts, drive workflows, generate exports, and subscribe to webhooks — all over OAuth 2.0.

**Areas:** Company · Business Applications · Accounting · Financial Close · Bookkeeping · Reporting · Compliance · Fintech · Software-as-a-Service · Belgium
